# /build — Build Clean

Use this skill during implementation to keep code modular, readable, and aligned with repo conventions.

## Steps
1. **Read economically**: Read only the relevant line ranges of target files before editing.
2. **Write modular code**: Keep functions small and single-purpose with shallow nesting and early returns.
3. **Zero duplication**: Extract shared helpers or parameterize variants instead of duplicating logic.
4. **Preserve context**: Keep unrelated existing comments, docstrings, and formatting intact.
